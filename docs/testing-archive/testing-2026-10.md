## 检查 8：实际 HTTP 联调发现同源别名问题

- 已启动：本地开发服务器 `http://127.0.0.1:3000`，健康探测 HTTP 200 且项目标题正确。
- 执行：`npm run check`（含脚本 lint）通过，随后 `npm run smoke:live`。
