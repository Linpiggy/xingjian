# 决策记录

只记“当时为什么这样定”，不记实施进度。倒序排列，只追加，不改写旧条目；某条失效时不删除，在“现状”里写明被哪条取代。

## 2026-10-30 生成失败按可恢复性分层

- 决策：模型输出只在两处放宽：未知字段丢弃而不是整份作废；仅结构性失败的天再请求一次，按 `dayIndex` 合并。JSON 语法错误、输出截断仍不修补、不重试。名称匹配在原文归一化之外接受"括号／分店修饰"的唯一前缀匹配，仍要求唯一候选。步行查询只对 `rate_limited`、`upstream_http`、`unavailable` 立即重查一次；`no_route` 与权限错误不重试，缺轨迹继续如实留空。地图代理与服务端 Web 服务改为两套独立本地额度。
- 理由：原有"一票否决"把供应商拼写噪声、模型多余字段与一次瞬时网络失败都放大成整份方案失败；重试只重复同一次读查询，不引入新数据来源，也未放松"不得虚构地点、路线或字段"的不变量。
- 现状：生效。JSON 修补与自动重发整份方案仍不做；两套额度仍是单进程内存计数。

## 2026-10-30 文档分层

- 决策：`AGENTS.md` 只留边界、不变量与验收；决策史进本文件；`DESIGN.md` 去掉数值副本与历史墓碑；`docs/testing.md` 只记状态，历史归档到 `docs/testing-archive/`。
- 理由：同一事实曾在三个文件里各写一遍（`DESIGN.md` 写 `#f7f5ef`、`planner.spec.ts` 断 `#f4f7f6`、规范写“暖纸松绿”），导致每次改动都在猜哪一版是当前。
- 现状：生效。

## 2026-10-30 UIArc 免费控件接入

- 决策：基础控件采用 UIArc 免费 MIT 公开源码，适配副本放 `src/components/arc`，固定上游版本、保留许可，只加必要依赖。
- 理由：需要一个已有键盘语义与状态设计的控件源，而不是继续手写按钮、折叠与日期条。
- 现状：生效。已接入按钮、输入、徽标、折叠、日期、进度，并在 2026-10-30 补了弹层、确认弹层、分段选择与行内展开；`src/components/arc` 之外的手写控件仍待收敛。

## 2026-10-30 结果页改垂直布局

- 决策：结果页取消桌面左右分栏、视口锁高与内层双滚动，改为“概览与日期 → 地图 → 每日安排”的单一主滚动区。
- 理由：并列布局在窄屏下要维护两套滚动与两处定位，回看路线与日程时容易丢失上下文。
- 现状：生效，取代此前的并列地图／日程布局。

## 2026-10-29 暖纸／松绿视觉方向

- 决策：画布改暖纸 `#f7f5ef`、阅读面 `#fffef9`、主操作 `#2a5d43`，首页采用纸卡与橙色便签；不做暗色主题。
- 理由：旅行提案需要纸感与留白，冷灰绿更像后台管理系统。
- 现状：生效。色板已收进 `src/app/globals.css` 的 `:root`，Arc 变量与 `--trip-*` 改为别名（2026-10-30）。字阶、间距、圆角、阴影尚未收进 `:root`，仍有多处字面值。

## 2026-10-30 MediaCrawler 定位

- 决策：MediaCrawler 只作后台社交资料采集端，不是路线引擎；采集端与经审核的授权索引分离，不塞进 Next.js 请求或每次生成。
- 理由：平台条款、授权与抓取边界需要独立处理，不能让采集行为进入用户请求链路。
- 现状：生效。限量真实验证返回 `robots_disallowed`，因此社交资料仍标为未接通，不用模型记忆冒充平台内容。

## 2026-10-28 社交笔记的证据等级

- 决策：社交笔记只作未核实的灵感，先匹配真实 POI 再核对路线；点赞数不作可靠性，帖内价格／营业／过敏不作事实；图片仅存本次会话 Blob。
- 理由：平台内容无核验能力，且图片站外展示授权与 Cookie 边界未确认。
- 现状：生效。

## 2026-10-13 高德接入方式

- 决策：高德只经服务端适配器访问，客户端走同源 `/_AMapService` 代理；客户端地图 Key 与服务端 Web 服务 Key 分离。
- 理由：安全密钥不能进 `NEXT_PUBLIC_*`，且需要集中校验 HTTP 状态与业务码。
- 现状：生效。

## 2026-10-13 不接入美团／大众点评

- 决策：取消美团、大众点评接入，改为评估社交资料作为推荐来源。
- 理由：平台授权与商用条款未解决。
- 现状：生效。日期未单独提交，依据为当时规范表述。

## 2026-10-13 只做 Light

- 决策：Figma 与实现只保留 Light，不自动跟随系统暗色。
- 理由：暗色需重新校验对比度与地图底图，赛事周期内无验证预算。
- 现状：生效，已写入 `DESIGN.md` 的不可协商条目。
